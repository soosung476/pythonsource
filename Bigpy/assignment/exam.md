## 문제 1 (난이도 하) — 정적 페이지 크롤링 & CSV 저장

### 학습 포인트

- `requests` + `BeautifulSoup` 기본 사용
- `select()` / `select_one()`으로 원하는 요소 찾기
- CSV 저장 (`csv.DictWriter`)

### 요구사항

1. `https://books.toscrape.com/` 에서 첫 페이지에 있는 책 20권의 **제목, 가격, 별점**을 크롤링하세요.
2. 콘솔에 다음 형식으로 출력하세요.

   ```
   1. A Light in the Attic | £51.77 | 별점: Three2. Tipping the Velvet | £53.74 | 별점: One...
   ```

3. 결과를 `books_top20.csv` 파일로 저장하세요. (컬럼: 순번, 제목, 가격, 별점)

### 힌트

- 책 하나는 `<article class="product_pod">` 안에 들어있습니다.
- 별점은 `<p class="star-rating Three">`처럼 class의 두 번째 값에 들어있습니다. (`tag['class']`로 리스트를 가져올 수 있음)

## 문제 2 (난이도 하) — 공개 API 크롤링 (인증 없음)

### 학습 포인트

- `requests`로 REST API 호출
- JSON 응답 파싱 (중첩 딕셔너리/리스트 접근)
- JSON 파일로 저장

### 요구사항

1. `https://api.frankfurter.dev/v1/latest?base=USD&symbols=KRW,JPY,EUR` 를 이용해 달러 기준 원화, 엔화, 유로 환율을 가져오세요.
2. 콘솔에 통화별로 출력하세요.

   ```
   1 USD = 1385.20 KRW1 USD = 147.32 JPY1 USD = 0.92 EUR
   ```

3. 결과를 `exchange_today.json` 파일로 저장하세요. (조회일자 포함)

### 힌트

- 인증키가 필요 없는 API입니다.
- 응답 구조에서 `rates` 키 안에 통화별 값이 들어있습니다.

## 문제 3 (난이도 중) — 인증키 필요한 API + 여러 도시 반복 조회

### 학습 포인트

- `.env` + `python-dotenv`로 API 키 안전하게 관리
- 여러 항목 반복 조회 후 리스트로 집계
- 예외 처리 (없는 도시명, 인증 실패)

### 요구사항

1. OpenWeatherMap에서 본인 API 키를 발급받아 `.env` 파일에 저장하세요.
2. 서울, 부산, 인천, 대구, 광주 **5개 도시**의 현재 기온과 날씨 상태를 조회하세요.
3. 5개 도시 중 **가장 더운 도시**와 **가장 시원한 도시**를 찾아서 출력하세요.

   ```
   === 도시별 현재 날씨 ===서울: 29.5도, 맑음부산: 27.1도, 구름 조금...가장 더운 도시: 서울 (29.5도)가장 시원한 도시: 부산 (27.1도)
   ```

4. 존재하지 않는 도시명이 들어와도 프로그램이 멈추지 않고 "조회 실패"로 넘어가게 처리하세요.
5. 전체 결과를 CSV로 저장하세요.

### 힌트

- 최고/최저를 찾을 때 `max()` / `min()`에 `key=lambda` 옵션을 활용해보세요.

## 문제 4 (난이도 중) — Selenium 또는 Playwright로 동적 페이지 + 로그인 세션 재사용

### 학습 포인트

- JS 렌더링 페이지를 브라우저 자동화로 크롤링
- 무한 스크롤 처리
- (심화) 로그인 세션 저장 및 재사용

### 요구사항

1. Selenium 또는 Playwright 중 하나를 선택해서, 로그인이 필요 없는 사이트(예: 아무 커뮤니티 게시판이나 무한 스크롤이 있는 사이트) 하나를 골라 접속하세요.
2. 페이지 끝까지 **무한 스크롤**하여 로딩되는 게시글(또는 상품, 뉴스 등) 제목을 최소 30개 이상 수집하세요.
3. 수집한 제목을 텍스트 파일(`titles.txt`)로 한 줄씩 저장하세요.
4. (선택 심화) 만약 로그인이 필요한 사이트로 진행한다면, 최초 1회 수동 로그인 후 세션(쿠키)을 저장해두고, 재실행 시 그 세션을 재사용하도록 구현해보세요.

### 힌트

- 무한 스크롤은 "스크롤 → 대기 → 페이지 높이 비교 → 높이가 같으면 종료" 패턴을 씁니다.
- 로그인 세션 재사용은 Playwright의 `storage_state`를 활용하면 편합니다.

## 문제 5 (난이도 상) — 종합: API + 동적크롤링 + 파일저장(xlsx, 이미지 포함) + 자동화

### 학습 포인트

- 여러 기법을 조합한 종합 크롤링 파이프라인 구축
- 엑셀에 텍스트 + 이미지 함께 저장 (`xlsxwriter`)
- 배치파일 + 작업 스케줄러로 자동화

### 요구사항

1. 아래 두 데이터 소스를 **하나의 프로그램**에서 순서대로 수집하세요.
   - **A. API**: TMDB(또는 다른 인증 필요 API)에서 현재 인기 영화 TOP 5의 제목, 평점, 개봉일, 포스터 이미지 URL을 가져오기
   - **B. 동적 크롤링**: Selenium 또는 Playwright로 각 영화 제목을 네이버(또는 다른 검색엔진)에 검색해서, 검색 결과에 나오는 실관람평 평점(또는 리뷰 수)을 가져오기
2. A와 B에서 얻은 정보를 **영화 제목 기준으로 합쳐서** 하나의 표로 정리하세요.
   | 순위 | 제목 | TMDB평점 | 개봉일 | 네이버평점 | 포스터 |
3. 결과를 엑셀(`.xlsx`) 파일로 저장하되, **포스터 이미지를 실제 셀에 삽입**하세요. (이미지 다운로드 → `BytesIO` → `worksheet.insert_image`)
4. 완성된 프로그램을 배치 파일로 만들고, Windows 작업 스케줄러에 **매일 정해진 시각**에 자동 실행되도록 등록하세요.

### 힌트

- API 결과(제목)를 그대로 검색창에 넣을 때, 특수문자가 있으면 오류가 날 수 있으니 예외처리를 고려하세요.
- 브라우저 자동화 부분은 오늘 배운 `page.goto()`, `page.wait_for_timeout()`, `page.inner_text()` 등을 그대로 응용하면 됩니다.
- 배치파일에는 반드시 `cd /d` 로 작업 경로를 먼저 지정해야 합니다.
