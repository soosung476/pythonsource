## 4. 데이터 소스 (2026-09-02 실제 접속 검증 완료)

KAMIS 농산물유통정보 — **부류별 일간 소매가격**.
API 키 불필요, Selenium 불필요. `requests` 한 번으로 **서버 렌더링된 HTML 표**가 그대로 옵니다.

```
https://www.kamis.or.kr/customer/price/agricultureRetail/catalogue.do
    ?action=daily
    &dateType=1
    &regday=YYYY-MM-DD          # 조회할 날짜
    &itemcategorycode=200       # 100 식량작물 / 200 채소류 / 400 과일류
    &convert_kg_yn=N
```

- `pd.read_html(io.StringIO(res.text))[-1]` → 바로 DataFrame
- 반환 컬럼: `품목 / 품종 / 단위 / 등급 / 당일(MM/DD) / 1일전 / 1주일전 / 2주일전 / 1년전 / 평년`
- 검증 결과 (2026-09-01): 채소류 53행, 식량작물 13행, 과일류 34행. 과거 날짜(2026-08-04)도 정상 응답.
- 실제 응답 예시:

  | 품목 | 품종 | 단위 | 등급 | 당일(09/01) | 1일전 | 1주일전 | 1년전 | 평년 |
  |---|---|---|---|---|---|---|---|---|
  | 배추 | 여름(고랭지) | 1포기 | 상품 | 5361 | 5278 | 5636 | 6820 | 6404 |
  | 수박 | 수박 | 1개 | 상품 | 24108 | 26047 | 26550 | 31472 | 28286 |
  | 오이 | 가시계통 | 10개 | 상품 | 11322 | 11246 | 11127 | 13338 | 13969 |

- `robots.txt` 확인함 — 이 경로는 제한 대상 아님. 그래도 `time.sleep(0.5)` 로 예의 지킬 것.
- **User-Agent 헤더 필수.**

### 반드시 알아야 할 함정 3가지
1. **주말·공휴일 데이터가 없음** (조사일 기준) → 날짜에 구멍이 생김. `rolling()` 걸기 전에 처리 필요.
2. **결측치가 `'-'` 문자열로 옴** (제철 아닌 품목). `pd.to_numeric(..., errors="coerce")` 필수.
3. **같은 품목도 품종·등급별로 여러 행** (예: 오이 → 가시계통/다다기계통/취청).
   식별 키를 `품목 + 품종 + 등급` 조합으로 잡아야 함.
